# Бриф для Claude Code — игра «Жизнь в лесу»

Полный дизайн-документ с деталями персонажей, зелий, врагов и т.д. — в файле
`жизнь-в-лесу-дизайн-документ.md` (лежит рядом). Открой Claude Code в этой же папке,
чтобы он видел оба файла.

## Что делаем

Пиксельная 2D-игра-выживание для ноутбука. Персонаж ходит по лесу, собирает ресурсы,
крафтит предметы, сражается с монстрами и боссами. Цель — победить Лешего и выйти из леса.

## Технологии (рекомендация)

- Один HTML-файл или простой набор: `index.html`, `game.js`, `style.css`
- HTML5 Canvas + обычный JavaScript, без фреймворков — так проще редактировать и понимать код
- Никаких серверов и установок — запускается двойным кликом по `index.html` в браузере
- Графика: на старте простые цветные фигуры/плейсхолдеры, потом можно заменить на пиксель-спрайты

## Как запускать

Открыть `index.html` в любом браузере (Chrome/Edge/Firefox). Работает офлайн,
ничего устанавливать не нужно.

## План разработки — делать по этапам, не всё сразу

### Этап 1 — MVP
- Экран выбора персонажа (4 варианта + выбор цвета глаз: синий/зелёный/красный/оранжевый/чёрный)
- Персонаж ходит по карте леса (стрелки или WASD)
- Заглушки вместо финальной графики — можно доработать позже

### Этап 2 — Ресурсы и голод
- Деревья с едой (яблоки, бананы, овощи) — можно собирать
- Полоска HP (50) и голода (100 максимум), голод снижается со временем

### Этап 3 — Крафт и выживание
- Инвентарь
- Рецепты: палка + уголь = костёр; спичка + яблоко = бомба
- Кровать и сон, смена дня и ночи

### Этап 4 — Бой
- Лук как основное оружие
- Волки — появляются ночью у леса, из них можно добыть мясо (жарится на костре, +1 к голоду)
- Пещеры как отдельная зона: летучие мыши атакуют, в глубоких пещерах сильнее; в пещерах добываются кристаллы и уголь

### Этап 5 — Боссы
- Баба-яга: кидает зелья (одно снимает 10 HP), может появляться с чёрной кошкой,
  которая говорит что-то полезное или бесполезное (случайно). После победы открывается её огород с морковью.
- Леший (финальный босс): 1000 HP, урон наносит только лук, охраняет выход из леса

### Этап 6 — Прогресс и магазин
- Алмазики за победу над боссами (не выдавать сразу много, чтобы нельзя было купить всё разом)
- Магазин одежды за алмазики
- Экран победы после боя с боссом: пиксельная картинка, 3 звезды, лицо побеждённого босса с крестиками вместо глаз

### Этап 7 — Город и финал первой части
- После победы над Лешим открывается город с NPC, с которыми можно говорить
- Из города можно вернуться обратно в лес
- Вторая часть — не делать сейчас, только заложить возможность продолжения

## Важно для Claude Code

- Не пытаться сделать всё за один раз — двигаться строго по этапам, тестируя каждый
- После каждого этапа — рабочая, запускаемая версия игры
- Персонажи и внешний вид (одежда, цвет волос) — см. дизайн-документ, раздел «Персонажи»
