# Игра «Жизнь в лесу»

Автор идеи: Алиса
Платформа: игра для ноутбука, пиксельная графика
Главная цель: выбраться из леса, победив Лешего — босса, который охраняет выход

## Персонажи на выбор

1. **Брюнетка** — прямые волосы, зелёная кофточка, синие штаны, чёрные кроссовки
2. **Блондинка** — кудрявые волосы, розовая майка, джинсы, чёрные кроссовки
3. **Мальчик тёмненький** — синяя кофта, чёрные штаны
4. **Мальчик блондин** — красная футболка, джинсы

Кастомизация:
- Цвет глаз: синий / зелёный / красный / оранжевый / чёрный
- Лицо — на выбор из нескольких вариантов
- Кроссовки чёрные, фиксированные (не меняются)

## Характеристики игрока

- Здоровье (HP): 50
- Голод: до 100

## Мир

- **Лес** — стартовая локация, полна опасностей
- **Город** — открывается после победы над Лешим, есть NPC для диалогов
- **Пещеры** — кристаллы (крафт магии/брони), летучие мыши (атакуют, в каждой следующей пещере сильнее)
- **Огород у домика Бабы-яги** — морковь (доступен после победы над ней)
- Деревья с едой в лесу — бананы, яблоки, овощи

## Выживание

- Нужно крафтить кровать и спать ночью
- Ночью у леса появляются волки и атакуют
- Из волков можно добыть мясо → пожарить на костре → +1 к голоду
- Костёр: крафт из палки + уголь (уголь добывается в пещерах)

## Крафт (примеры комбинаций)

- Спичка + яблоко = бомба
- Палка + уголь = костёр
- Кристаллы из пещер → магические предметы / броня
- Оружие можно улучшать (понадобится для финального босса)

## Зелья (находятся в доме)

- Зелёное — минус 1 HP каждую секунду (опасное)
- Синее — восстанавливает здоровье

## Враги и боссы

- **Стая волков** (ночь, у леса) — опасны, но и полезны (дают мясо)
- **Летучие мыши** в пещерах — атакуют, сильнее в глубоких пещерах
- **Баба-яга** (мини-босс) — кидается зельями, одно снимает 10 HP; иногда появляется с чёрной кошкой, которая говорит что-то полезное или бесполезное (случайно)
- **Леший** (финальный босс) — 1000 HP, охраняет выход из леса, побеждается только луком, бой долгий и сложный

## Экономика

- За победу над боссом — алмазики
- На алмазики покупается одежда/кастомизация
- Награда не выдаётся сразу большими пачками — чтобы нельзя было купить всё сразу

## Экран победы (после боя с боссом)

- Пиксельная картинка
- Оценка — три звезды
- Изображение побеждённого босса с крестиками вместо глаз

## Финал (часть 1)

- После победы над Лешим — открывается город с NPC
- Можно вернуться в лес
- Вторая часть — в планах на будущее
